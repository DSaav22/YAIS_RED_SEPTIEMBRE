# Hojas técnicas 3D — La Isla de los Acuerdos

Estas hojas convierten el moodboard 3D en referencias de producción. Se usan para mantener consistencia entre el modelado headless, las animaciones y las escenas de PlayCanvas.

## Reglas de producción

- Los personajes se modelan con frente, perfiles, espalda, tres cuartos, altura común y expresiones definidas.
- Las piezas grandes se construyen con vistas frontal, lateral, superior y módulos desmontables.
- Los props que se agarran, abren o giran incluyen grosor y vista trasera/inferior.
- La geometría final debe mantener silueta, paleta, accesorios y proporciones de la hoja aprobada.
- Las imágenes no sustituyen medidas reales: el script de Blender debe fijar unidades, pivotes, colisiones y nombres de objetos.
- Las poses son referencias de animación; no son sprites ni una captura directa de movimiento.
