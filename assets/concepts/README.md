# Conceptos visuales — La Isla de los Acuerdos

Estas imágenes son referencias visuales generadas para definir dirección artística, composición móvil y familias de assets. **No son todavía assets finales de producción**: antes de incorporarlas al juego hay que separar elementos, corregir textos, validar legibilidad en teléfonos y exportar sprites/componentes consistentes.

La conversión 3D tiene dos niveles: [referencias 3D artísticas](../references-3d/README.md) y [hojas técnicas multivista](../references-3d/technical/), que deben aprobarse antes de generar modelos con Blender headless.

## Archivos

- `isla-acuerdos-core-screens.png`: mapa y cuatro pantallas núcleo.
- `isla-acuerdos-expansion-archipelago.png`: expansión hacia habilidades, convivencia, entorno e IA/inglés futuros.
- `isla-acuerdos-character-props-sheet.png`: mascota, personajes de apoyo y accesorios.
- `isla-acuerdos-environment-sheet.png`: mapa, islas, piezas de entorno y props ambientales.
- `isla-acuerdos-mobile-ui-kit.png`: componentes de interfaz y pantallas en formato teléfono.
- `isla-acuerdos-gameplay-cards.png`: cartillas de elección para las mecánicas sociales, de equipo y ambientales.

## Dirección recomendada

- Diseño **portrait-first** para teléfono, proporción base 9:16.
- La rotación a landscape puede ser una adaptación posterior para tablet o aula; no debe ser requisito para jugar.
- Las imágenes funcionan como moodboard/brief de arte, no como spritesheets listos para Phaser.
